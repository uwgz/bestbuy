Giveaway rules

From time to time {{ business.name }} gives prizes to random visitors of this website. Here's how it works.

How winners are chosen

When a giveaway starts, our system secretly picks a random moment within the giveaway period for each prize. The first visitor to open a page of this website after that moment wins. Nobody — including our staff — can choose the winner.

No purchase needed

You don't have to buy anything or sign up. Just visit the website while a giveaway is running.

Your winning code

Winners see a message with the prize and a unique code (for example VE-7KQ4-92MX). The code is the proof of your win: we check it in our system before handing over the prize. A screenshot without a valid code is not accepted, and each code works only once.

Collecting your prize

Bring your code to our store{% if business.address %} at {{ business.address }}{% endif %}, or send it to us on WhatsApp{% if business.phone %} ({{ business.phone }}){% endif %}, within {{ claim_days }} days of winning. After that the code expires and the prize is no longer available.

For money prizes we may ask for an ID, and the prize is given to the person named on it.

Fair play

  • One prize per person and per giveaway.
  • Prizes can't be exchanged for something else unless we agree.
  • Codes that were changed, copied or obtained by cheating are void.
  • We may end a giveaway early; prizes already won can still be collected.

Questions? Contact us.
